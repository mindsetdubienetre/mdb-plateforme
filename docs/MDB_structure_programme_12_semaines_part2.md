# PHASE 3 — ACTIVATION (Semaines 7 à 9)

**Ancrages scientifiques** : Gregg Braden (champ quantique), Antonio Damasio (émotions et décision), Martin Seligman (PERMA), Richard Schwartz (IFS — Internal Family Systems), Bandler & Grinder (PNL — ancrage)

# PHASE 4 — INTÉGRATION (Semaines 10 à 12)

**Ancrages scientifiques** : Rick Hanson (Hardwiring Happiness), Marsha Linehan (DBT — régulation autonome), Gabor Maté (retour à soi), Carl Jung (psychologie analytique — rituel de clôture)

**Mécanisme clé** : L'intégration c'est quand le nouveau comportement devient automatique — le nouveau circuit neuronal est assez fort pour prendre le relais sur l'ancien. Elle n'a plus besoin de forcer : elle est devenue quelqu'un d'autre, de l'intérieur.

# ORDRE DE DÉBLOCAGE

Chaque semaine se débloque automatiquement **7 jours après** le déblocage de la précédente (règle stricte validée avril 2026 — la répétition quotidienne est le travail neuro).

Chaque phase se débloque après la célébration de la phase précédente.

**Progression** : S1 → S2 → S3 → 🎉 Phase 1 → S4 → S5 → S6 → 🎉 Phase 2 → S7 → S8 → S9 → 🎉 Phase 3 → S10 → S11 → S12 → 🎉 Programme terminé

# NOTE POUR LE DÉVELOPPEMENT

Tous les slugs sont uniques et suivent le format `[type]-[thème]-s[numéro]`. Ils peuvent être utilisés directement comme identifiants dans la base de données Supabase et dans les routes de la plateforme.

Le détail du contenu de chaque exercice (questions d'introspection, scripts EFT complets, textes de méditations, scripts d'auto-hypnose) sera défini séparément — ce document sert de **carte structurelle** pour le développement.
